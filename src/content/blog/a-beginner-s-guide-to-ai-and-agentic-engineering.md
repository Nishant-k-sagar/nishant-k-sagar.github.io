Software Engineering has been changing almost every decade. From writing Machine code to writing the Python abstraction code has took a significant amount of time. But from last 5 years or so - Software engineering has been one of the major field with the highest degree of change. From handwritten code, tests, automation scripts to AI written code, test suites, automation pipelines running in prod - has been some cinematic level real world change. You could just prompt and things/logic/programs/codes/tests/verifications etc. gets done in plain English. Just wonderful stuff.

As this change took less than a decade, and I am fond of system's working and familiarities - It captured my attentions and I have devoted a good amount of time learning AI/agentic concepts. Thus, I wanted to write up how to use these agents in the most meaningful way depending on the type of work. You engage with the guide - It will be going from early to real world use.
